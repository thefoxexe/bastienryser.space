# Logo bastienryser

Monogramme **br** : le b et le r partagent la même panse, les initiales en un seul trait.

| Fichier | Usage |
|---|---|
| `br-symbol.svg` | Master (trait 30) — tailles moyennes et grandes |
| `br-symbol-small.svg` | Coupe petite taille (trait 40, panse plus ouverte) — sous 24 px, favicon |
| `br-symbol-white.svg` | Version blanche pour fonds sombres |
| `br-app-icon-512.png` | Icône d'application (marque #f5f5f7 sur #1d1d1f) |
| `concepts.png` | Les trois pistes présentées (A retenue) |

- **Couleurs** : encre `#1d1d1f` sur `#f5f5f7` (clair), `#f5f5f7` sur `#000000` (sombre). Monochrome uniquement.
- **Police** : San Francisco (système Apple), Inter en repli. Nom écrit `bastienryser` + `.space` en gris.
- **Zone de protection** : au moins l'épaisseur du trait tout autour. **Taille minimale** : 16 px (coupe petite taille).
- Les masters sont tracés avec un trait (`stroke`) ; à vectoriser en contours avant une impression ou une broderie.
- Aucune recherche de marque n'a été faite : à prévoir avant un dépôt.
